# Interactive Periodic Table of Elements

A responsive, dynamic **Periodic Table of Elements** built from scratch using vanilla web technologies. This application fetches real-time atomic data from an open-source API to map out all 118 elements.

## Live Demo
**[Click here to view the live project!]https://frozenking0.github.io/periodic-table/**

## Features
**Live 118-Element Fetch:** Automatically requests and streams chemical data from a remote server using asynchronous JavaScript.
**Smart Search Filter:** Real-time search functionality that fades out unmatched elements as you type names or chemical symbols.
**Interactive Details Panel:** Displays specific element metrics (atomic number, group classification) directly on-screen when a card is clicked.
**Fully Responsive Grid:** Uses CSS Grid and media queries to seamlessly collapse from an 18-column scientific layout to a mobile-friendly 4-column feed.
**Modern Aesthetic:** Clean UI utilizing eye-friendly color themes, soft gradients, and interactive hover transformations.

## Built With
**HTML5:** Semantic structure and dataset layout containers.
**CSS3:** Custom layouts using Grid, Flexbox, media queries, and transition animations.
**JavaScript (ES6):** Asynchronous functions (`fetch`, `async/await`), DOM manipulation, and dynamic event streaming.
